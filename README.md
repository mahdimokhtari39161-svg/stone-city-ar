# Stone City AR — استودیوی طراحی نما و شهرسازی

نسخه مستقل برنامه Stone City، بر پایه فایل نسخه ۳۷.

## قابلیت‌ها
- محیط طراحی سه‌بعدی نمای ساختمان و مصالح سنگی
- ابزارهای شهرسازی، فلاورباکس و نورپردازی موجود در نسخه ۳۷
- پیش‌نمایش AR با تصویر زنده دوربین گوشی و تنظیم دستی جایگاه، اندازه و چرخش طرح
- نصب به‌صورت PWA و ذخیره پوسته اصلی برای مراجعه‌های بعدی

## انتشار
GitHub Actions با هر Push به شاخه main یا master، محتوای مخزن را روی GitHub Pages منتشر می‌کند.
پس از اولین اجرای موفق workflow، در Settings → Pages بررسی کنید Source روی GitHub Actions باشد.

## استفاده از دوربین
صفحه را با HTTPS در Chrome گوشی باز کنید، قابلیت AR را اجرا کنید و مجوز Camera را بدهید. دسترسی دوربین مرورگر در محیط امن HTTPS یا localhost کار می‌کند.

## محدوده AR
این نسخه تصویر مدل را روی تصویر زنده دوربین می‌اندازد و تنظیم موقعیت/اندازه/چرخش دستی است؛ تشخیص خودکار سطح دیوار، ردیابی فضایی و قفل خودکار مدل به ساختمان در این نسخه وجود ندارد.

## نکته آفلاین
پوسته برنامه و فایل‌های اصلی cache می‌شوند؛ اما بعضی مدل‌ها و کتابخانه‌های سه‌بعدی و فونت از CDN بارگیری می‌شوند و برای بارگذاری اولیه آن‌ها اینترنت لازم است. بنابراین این نسخه را نباید کاملاً آفلاین دانست.
